# План развития

Номера разделов обозначают направления развития, а не автоматическую лестницу до `1.0`. Проект может продолжать экспериментальную линию версиями `0.10`, `0.11` и далее. Критерии стабильного выпуска определены в [VERSIONING.md](VERSIONING.md).

## 1.0 — только после подтверждения зрелости

Не планируется по номеру предыдущего выпуска. Рассматривается только после выполнения критериев стабильности, совместимости, воспроизводимости и внешней проверки из `VERSIONING.md`.
