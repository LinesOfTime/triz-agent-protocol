# Terminology

- **ARIZ:** Algorithm for Inventive Problem Solving; a structured method for difficult inventive problems.
- **Cause-conflict analysis:** connects observable disadvantages to contributing causes and conflicts.
- **Function:** an interaction in which one component changes or maintains another.
- **IFR:** directional model of a desired result with minimal added cost and harm.
- **Operational zone/time:** where and when the conflict occurs.
- **Physical contradiction:** one element requires opposing properties.
- **Resource:** something already present in or around the system that can contribute.
- **Technical contradiction:** improving one characteristic deteriorates another.
- **TRIZ-Lite / Guided ARIZ:** original project workflows, not classical terms or official ARIZ versions.
