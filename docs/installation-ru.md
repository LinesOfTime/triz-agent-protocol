# Установка и подключение

## Использование без установки

Скопируйте нужный файл из `templates/` в проект и заполните его. Этот режим подходит для любой языковой модели, способной читать Markdown.

## Командная строка

Требуется Python 3.10 или новее.

```powershell
git clone https://github.com/LinesOfTime/triz-agent-protocol.git
cd triz-agent-protocol
py -m pip install -e .
triz analyze analysis.json --problem "Опишите проблему" --goal "Опишите проверяемую цель"
triz validate analysis.json
triz render analysis.json --language ru --output analysis.md
```

`analyze` создаёт черновик, а не завершённое решение. До заполнения обязательных полей команда `validate` должна сообщать об ошибках.

## Codex и совместимые агенты

Скопируйте каталог `skills/triz-problem-solving` в каталог навыков используемого агента. Для Codex расположение зависит от способа установки; не заменяйте уже существующий одноимённый навык без просмотра различий.

Вызов:

```text
Используй $triz-problem-solving для анализа противоречия. Отдели доказательства от предположений и предложи проверяемый обратимый следующий шаг.
```

Для постоянного правила проекта можно добавить в `AGENTS.md`:

```markdown
При конфликтующих требованиях, повторяющейся регрессии или архитектурном компромиссе используй `triz-problem-solving`. Не применяй полный анализ к рутинной задаче с установленным решением.
```

## Локальные модели

Передайте модели `templates/TRIZ_TASK.md` или содержимое соответствующего reference-файла навыка. Проверку структуры выполняйте локальной командой `triz validate`; её результат подтверждает форму JSON, но не истинность анализа.
