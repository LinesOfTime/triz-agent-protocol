# Context Funnel Benchmark v1

Первый замороженный структурный пример для проверки обнаружения критических файлов. Он не является экспертно валидированным benchmark качества рассуждений.

## Проведение

1. Передайте участнику только `task.md` и каталог `repository/`.
2. Не передавайте `gold.json` до фиксации результата.
3. Результат сохраните по форме `result.example.json`, перечислив фактически найденные зависимости и неподтверждённые утверждения.
4. Выполните:

```bash
triz benchmark benchmarks/context-funnel-v1/gold.json result.json
```

PASS требует обнаружения всех заранее зафиксированных критических файлов и отсутствия неподтверждённых утверждений. Precision выводится отдельно и не входит в PASS v1.
