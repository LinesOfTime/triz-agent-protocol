# Guided ARIZ

Use only when a meaningful conflict persists after ordinary analysis. This is an original guided workflow, not an official reproduction of ARIZ.

## Problem model

1. Express a mini-problem that preserves the existing system where possible.
2. Identify product, tool, and conflicting interaction.
3. Describe two extreme configurations with benefits and harms.
4. Select the primary useful function to preserve.

## Conflict localization

5. Identify operational zone and time.
6. Inventory internal, environmental, temporal, informational, and system-level resources.

## Ideality and contradiction

7. Formulate the IFR.
8. State the physical contradiction if supported.
9. Apply separation and resource transformations.

## Concepts and verification

10. Generate distinct mechanisms, not paraphrases.
11. Check invariants and new problems.
12. Define falsifiable tests.
13. Recommend the smallest reversible experiment.

Request missing evidence rather than filling gaps with plausible detail.
