# TRIZ-Lite

1. Record evidence and separate assumptions.
2. State one observable goal and invariants.
3. Formulate an IFR without naming a preferred implementation.
4. State the main technical contradiction.
5. Inventory resources already available.
6. Propose at least two materially different mechanisms.
7. Define tests that can reject each mechanism.
8. Recommend a reversible next step, or stop if evidence is insufficient.

Output must conform to `schemas/analysis.schema.json` with `mode: lite`.
