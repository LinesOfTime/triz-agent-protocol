# Contradiction analysis

## Technical contradiction

```text
If [control parameter] changes toward [state A], [useful result] improves,
but [harmful result] worsens.
```

Record the inverse configuration to prevent one-sided framing.

## Physical contradiction

```text
[Element] must have [state A] for [benefit A],
and must have [opposing state B] for [benefit B].
```

Test separation in time, space/subsystem, by condition, between system levels, or by transforming the interaction. Do not force a physical contradiction when evidence supports only a trade-off.
